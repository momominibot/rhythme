What this build does

Local records
Saved form entries use this origin’s browser storage. There is no app-layer encryption or account separation. Someone with access to this browser profile may be able to read them.
Luna guide
Prepared educational answers work locally. This guide does not read your health records, send your messages or persist the conversation. Older saved Luna conversations remain available in the legacy section below.
Online features
Account sign-in requires a configured authentication service; check the account page for verified status. Authenticated AI chat, premium access and cloud backup remain unavailable. This build has no Face ID app lock, two-factor authentication or implemented research-sharing control.
Network & sources
Web pages can load fonts and assets from external services. Opening a source link visits its publisher. Some other tools have server request paths; local records are not automatically attached to Luna. This page is not a promise that every app feature operates offline.

Changing browser, origin or app installation can show a different set of records. These controls do not delete accounts, other devices, previously downloaded files or records held by a service.

Delete or export local data

No items are selected automatically. Legacy entries keep their original contents unless you explicitly choose to delete them. Unrecognized storage keys are left untouched.

You can prepare an export before deleting. Choosing items or opening the review does not delete anything.
